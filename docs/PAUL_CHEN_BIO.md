## 🏗 代表性專案 (Signature Projects)

### 🔗 1. xdxd.im - 連結重塑工具 (Link Reshaping Tool)
*   **核心價值**: 為 URL 穿上具備語義的「智慧外殼」，解決 Threads、LINE 等平台預覽破圖與「視覺不信任」問題。
*   **獨家協議**: 實作 **GIP 協定**，透過「完整、韌性、感性」三層邏輯強化使用者的圖像記憶。
*   **功能**: 內建指引空間 (Guidance Space)、標記工作室 (Marker Studio) 與記憶收藏箱 (Memory Box)。

### 🖼 2. Post Image Renderer - 社群媒體自動化製圖
*   **技術核心**: 基於 **Go** 與 **Headless Chrome** 構建的高效能渲染引擎。
*   **亮點**: 獨創 **Markdown 自定義解析邏輯 ([P1]-[P4])**，能將純文字稿自動轉換為高質感的 Glassmorphism 風格圖卡，並支援多語系自動路由。

### 🕷 3. Headless OG Image 2.0 - 韌性爬蟲系統
*   **突破點**: 解決現代網頁反爬蟲與 Cloudflare 阻擋問題，將連結預覽抓取成功率由 25% 提升至 **85%**。
*   **兜底機制**: 實作「無預覽則截圖」的智能回退機制，確保視覺體驗的一致性。

### ☁️ 4. AI 內容行銷自動化矩陣
*   **主題轉圖文**: 輸入關鍵字，Agent 自動規劃並產出七日份高品質社群圖文。
*   **AI 影片字幕 API**: 高併發後端架構，自動完成影片語音識別與字幕生成。
