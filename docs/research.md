# 零壹科技 (Zero One Tech) 企業情報研究

## 1. 核心轉型方向 (2024-2025)
*   **子公司成立**：2024 年 4 月成立「聯壹數位」，專攻 Cloud-native (雲原生)、多雲管理、AI 基礎架構。
*   **四大核心解決方案 (2025)**：
    1. IT 基建 AI 化 (AI-Ready Infrastructure)
    2. 資安韌性 (Security)
    3. 雲端運算與服務 (Cloud)
    4. 人工智慧應用 (AI Applications)
*   **NVIDIA 合作夥伴**：台灣主要的 NVIDIA GPU 伺服器代理商，擁有強大的硬體底層優勢。

## 2. AI 產品與策略
*   **GenBI (生成式智慧商業分析)**：預期生成式 AI 在 2024-2025 大爆發，重點在於 RAG、AI Agent 整合。
*   **代理生態系**：將 Tableau (BI)、Salesforce (CRM) 與 AI 技術整合。推動「Agentic Analytics」(代理分析)，讓 AI Agent 協助數據清洗、可視化與決策。
*   **從一到零的 PoC**：強調協助企業客戶進行 PoC (概念驗證)，這需要強大的 Pre-sales 和解決方案顧問能力。

## 3. 面試對齊關鍵點 (Key Alignment Points)
*   **技術實力**：強調對 LLM (OpenAI, Claude, Azure OpenAI) 的整合能力。
*   **開發框架**：對 LangChain, Hugging Face, 以及目前最新的 **MCP (Model Context Protocol)** 的熟稔度將是巨大加分項。
*   **工程化能力**：熟悉 Docker/Kubernetes 容器化部署，能將 AI 模型「產品化」而不只是實驗室版本。
*   **產業話語權**：強調「從純技術開發到協助客戶落地」的轉化能力，符合其「顧問職」的需求。
