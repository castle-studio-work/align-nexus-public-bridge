# Align-Nexus (The Alignment Protocol)

`align-nexus` is the abstracted core of the Castle Studio AAA alignment engine. It operates on a simple, powerful protocol: **Pool ➔ Target ➔ Outcome.**

## Architecture
- **`pool/`**: Your source of truth. Raw facts, project logs, and core identities.
- **`targets/`**: Your mission objectives. Job descriptions, RFIs, or content briefs.
- **`intelligence/`**: Contextual insights. Market research, company jargon, and constraints.
- **`outcomes/`**: The synthesized results. High-quality Markdown documents tailored to the target.

## How to use
1. **Define the Fact Pool**: Create a JSON in `pool/` containing your baseline information (e.g., `profile.json`).
2. **Define the Target**: Create a JSON in `targets/` describing what you want to achieve or satisfy (e.g., `job-jd.json`).
3. **Execute Alignment**:
   ```bash
   cd engine
   go run . -id  -pool 
   ```
4. **Refine**: Review the generated Markdown in `outcomes//final.md`.

## The "Good Taste" Standard
Align-Nexus doesn't just filter data; it **synthesizes intent**. Every output must follow these rules:
- **Zero Fluff**: If it doesn't solve a target requirement, it doesn't belong in the Outcome.
- **Terminology Echo**: Adopt the Target's language and vocabulary precisely.
- **Strategic Persona**: Ensure the tone and perspective are perfectly adjusted for the target audience.

## Outcome Structure
- **Synthesis**: A strategic overview matching the persona to the target.
- **Aligned Evidence**: Project facts and evidence rewritten for the target context.
- **Alignment IR**: The intermediate structured JSON (`alignment.json`) for audit and iterative refinement.
